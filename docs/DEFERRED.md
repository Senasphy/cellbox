# Deferred specification details

This report records what is still missing from the requested build. The goal remains the full project; these omissions do not count as acceptance.

## Core blockers

- Phase 3 still lacks two requested proofs: a live hosted-model fix-loop and the marked Python pytest integration against the Docker server. No `OPENAI_API_KEY` is present. `python3` has no pytest installed; the offline `uv` setup was blocked because its cache lacks the `pygments` wheel required by pytest, and the earlier online setup stalled, so I stopped rather than spend more time on dependency installation. On 2026-11-21, the Docker runtime contract, API walkthrough, and full Docker-backed Playwright dashboard flow passed locally. After fixing the native API/runtime output-cap mismatch and restoring OCI image-config environment variables (including PATH), direct Python SDK live checks and the fake-model fix-loop also passed against a temporary native server. The focused Docker contract, API walkthrough, Playwright flow, and crash-recovery walkthrough all passed locally. CI has not been rerun; run [44623183371](https://github.com/Senasphy/cellbox/actions/runs/44623183371) is historical evidence of the shell failure before the local EOF fix.
- Phase 4 is not accepted: the native backend now has an initial `Runtime` with OCI image pull/flatten, namespace/cgroup session creation, bounded command execution with live capped stdout/stderr chunks and per-exec signals, CPU/memory/PID, optional cgroup I/O stats, cumulative OOM-kill counters in session metrics, OOM-killed and PID-limit exec classification with memory/PID breach audit records, cleanup, root-confined file read/write/list/delete (atomic writes and regular-file read caps), capped tar archive/extract with full-path prevalidation, interactive PTY streams with resize, and a soft per-session disk quota watcher. The watcher scans allocated bytes in the writable overlay every two seconds, freezes and kills on quota breach or measurement failure, and records the breach with the failed session state in one SQLite transaction. It also polls cgroup OOM/PID counters every two seconds and records/stops a session when either occurs outside an active exec. Focused scanner and SQLite transaction tests pass, as do `go vet ./...` and a CLI build. The shared basic runtime contract passes when run from a dedicated delegated user scope. The host's default service cgroup still contains shared processes and does not delegate controllers; the test must use `systemd-run --user --scope -p Delegate=yes` and a statically linked test binary. The host free-space admission floor is also implemented. A live native quota-overrun check confirmed that writes over the limit kill the session and emit a disk breach. The watcher has a soft-limit overshoot window and counts allocated file/directory blocks. Full cleanup/chaos coverage remains missing or incomplete. The shared API now supports terminal reconnect with a 256 KiB ring and 30-second grace period; the Docker-backed Playwright flow passed, but a native-backend reconnect run has not been performed. The grace period is fixed rather than configurable. These gaps keep Phase 4 acceptance pending. The `cellbox-exec` helper receives requests over a pipe, applies rlimits, clears capabilities, sets no-new-privileges and seccomp, closes inherited descriptors, and reports launch errors over a close-on-exec pipe. Host file operations use `/proc/<init-pid>/root` with `openat2` confinement rather than the specified init file-operation messages. The host currently permits only one active exec or terminal per sandbox. Native exec timeout sends SIGTERM to the process group and escalates to SIGKILL after two seconds; the session stays available afterward, while Docker timeout still terminates its container. PID 1 now reaps adopted zombie descendants after SIGCHLD while preserving the helper process exit statuses owned by Go. A live descendant that escapes the native process group remains until session cgroup cleanup.
- The Docker backend has no enforced per-session writable-layer disk limit and is not suitable for hostile workloads.
- Phase 5 has an initial HTTP/HTTPS egress path for native and Docker backends: `none`, host/port allowlists, and configured `internet` mode; per-session Unix proxy sockets; loopback forwarder and proxy environment; IDNA host normalization; DNS resolution with all-address private/reserved-range checks; direct dialing to the validated IP with peer verification; a dedicated `egress_log` table with a paginated endpoint; and matching allow/deny audit events. The dashboard can choose an image and network mode when creating a session, and configure allowlist entries as `host:port`; the Network tab filters records, refreshes recent activity, and pages through older decisions. On 2026-11-22, `CELLBOX_DOCKER_SOCKET=/run/docker.sock make test-integration` passed: the Docker runtime contract passed, and the live egress test proved direct bypass to `1.1.1.1` failed, `example.org:443` was denied with `policy_denied`, and allowlisted `example.com:443` succeeded with `policy_allowed`. Native delegated-scope checks also passed using a statically linked test binary: in-sandbox `wget` to `1.1.1.1` failed, while allowlisted `pip download` from PyPI and `git ls-remote` from GitHub succeeded through the proxy. A cgo-linked native test binary failed because glibc attempted the deliberately denied `clone3`; static linking is required for native checks. The required section 11 test cases are covered by the focused proxy suite and these live checks. Bandwidth caps are not implemented; broader production threat-model review remains outstanding. Phase 5 remains pending until that security review confirms the address and DNS controls.
- Phase 6 is not accepted. Docker advertises TTY exec support; native advertises interactive PTY support but not TTY exec. Exec and terminal launches now merge session environment values with request overrides. The pool asynchronously prefetches configured curated images at startup, refills after cold no-network sessions, atomically claims matching idle sandboxes, applies requested limits, retires entries at ten minutes, retries failed image prefetch/refill with capped exponential backoff and jitter, and exposes readiness and warm/cold latency metrics. The eval-runner now includes checks for parent-after-snapshot, sibling-fork, and child-to-parent isolation, but these checks have not been run against a live service. Native snapshot capture freezes the session cgroup and copies the upper tree; chains at the overlay depth threshold now trigger merged-root copying into a marked flattened base, and future fork traversal stops at that base. The flat copy excludes `/dev`, `/proc`, `/sys`, and `/run`, preserves filesystem metadata and xattrs, and reflinks regular files where supported. Python pytest and the TypeScript SDK test suite remain outstanding (`vitest` is unavailable).

## Recently repaired core wiring

`SpawnInit` re-executes the service binary as `cellbox-init`. The existing `cmd/cellbox/native_init.go` hook dispatches that argv[0] to `RunInit`; init installs the default seccomp filter after its mount setup and before reporting ready. Init accepts bounded exec requests, streams capped stdout/stderr chunks over the control socket, accepts per-exec signals, and returns exit status. Each workload runs through the short-lived `cellbox-exec` helper with rlimits, cleared capabilities, no-new-privileges, seccomp, and a close-on-exec error pipe. A native Runtime creates overlay-backed sessions under per-session cgroups, pulls and flattens host-architecture OCI images, and supports command execution, stats, limit updates, kill, and destroy. Root-confined host file operations and capped, prevalidated archive extraction are implemented. Init-mediated file operations remain incomplete. Focused native package checks, vet, and a static Linux amd64 build pass locally. The shared basic contract has also passed against this backend in a delegated user scope; full Phase 4 acceptance remains unproven because the security, resource enforcement, leak/chaos, and benchmark evidence is incomplete.
