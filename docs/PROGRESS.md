Added a `scratch`-based Docker image and demo Compose setup using the Docker backend, host socket, and loopback-only published port. Added an initial `CHANGELOG.md` with an Unreleased section and current acceptance limitations. `bash -n`, YAML parsing, `docker compose config`, and `systemd-analyze verify` passed. Static CGO-disabled Linux amd64/arm64 builds with release ldflags both succeeded; the amd64 binary printed the embedded version. GoReleaser, Syft, and Cosign are not installed here, so the release pipeline itself was not exercised. The Dockerfile built successfully with build context reduced from 101 MB to 64 KB, and the resulting image printed its embedded `dev` version; the full Compose demo service was not started. The compose demo grants host Docker socket authority and is documented for local use only. Added a tag-triggered GoReleaser workflow and statically parsed its YAML. A public AUR package is deferred because the GitHub source repository is private. Release execution, package build, external security review, `staticcheck`/`golangci-lint`/`govulncheck`, 1-hour soak evidence, and demo recording remain outstanding.
