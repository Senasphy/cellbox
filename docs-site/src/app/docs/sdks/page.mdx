# SDKs & Agent Tools

CellBox ships lightweight, zero-bloat clients and agent integrations directly in the repository under `sdk/` and `cmd/cellbox`.

| Integration | Package / Location | Best For |
| --- | --- | --- |
| **Python SDK** | `sdk/python` (`cellbox-sdk`) | Sync & `asyncio` agent loops, evaluation runners, Jupyter/data tasks |
| **TypeScript SDK** | `sdk/typescript` (`@cellbox/sdk`) | Node.js / browser / agent workers using native `fetch` + `AsyncIterable` |
| **Go Client** | `github.com/senasphy/cellbox/sdk/go` | Go services with zero external transport dependencies (`net/http`) |
| **MCP Server** | `cellbox mcp` (`stdio` / Streamable `http`) | Plug-and-play coding agents (Claude Desktop, Cursor, custom MCP hosts) |
| **Model Tool Schemas** | `sdk/tools/openai.json`, `anthropic.json` | Direct LLM function calling with bounded 16 KiB head/tail output clipping |
